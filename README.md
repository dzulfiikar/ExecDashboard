## Fork Status

The original Hygieia Executive Dashboard project was archived on June 1, 2023 and is no longer maintained upstream. This fork is maintained on a personal, best-effort basis to preserve the project, refresh documentation, and support community-driven fixes where practical.

Near-term work is focused on making the fork safer and easier to run for personal use first, then gradually maturing dependency and package versions, build tooling, runtime configuration, and release practices.

Because this is a legacy application, treat it as a starting point that requires review before production use. The stack includes Java 8, Spring Boot 1.5.9, Angular 4, Node 8-era tooling, and MongoDB-backed services.

## Project Overview

Hygieia Executive Dashboard provides executive-level delivery and engineering metrics using a Spring Boot API, scheduled analysis jobs, MongoDB data storage, and an Angular single-page UI. It was designed to consume Hygieia-style collector data and present rollups for portfolio and leadership reporting.
